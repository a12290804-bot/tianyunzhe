# 《天運者》v6.7 戰爭殘酷・紅顏禍水 文本包

## 檔案清單
- `v6_7_war_text.js`：可直接掛載於遊戲的 IIFE 腳本（寫入 `window.WAR_TEXT`），對應 `inbox/v6_7_war_text.js`。
- `v6_7_war_text.json`：同份資料的純 JSON 備份，方便後台檢查或工具匯入。

## 內容統計
- **總手寫條目**：四百三十七條（零重複、零阿拉伯數字、零禁用詞）
- **通用 `"_"`（五十二條）**：
  - `lastwords`：陣亡士兵遺言（四十句，寫實樸素、具生活感）
  - `postwar`：城破之後、處置抉擇前畫面（六版）
  - `famine`：前線斷糧畫面（六版，無血腥細節）
- **三十五位紅顏專屬（每人十一條，共三百八十五條）**：
  - `warfor`：衝冠一怒・要你出兵（三版）
  - `mawei`：兵諫・三軍要求處死她時的反應（二版，楊貴妃強化馬嵬坡史詩分量）
  - `mawei_die`：賜死之後留下的最後一句話（二版，貫徹愛到恨、恨也是愛）
  - `mawei_defy`：拔劍護她、斬殺帶頭者後的反應（二版）
  - `mawei_bear`：你在三軍面前說「罪在朕躬」後的反應（二版）

## 掛載方式
於遊戲 HTML 中直接以 `<script src="inbox/v6_7_war_text.js"></script>` 載入，即可透過 `window.WAR_TEXT["_"]` 與 `window.WAR_TEXT[id]` 讀取對應字串陣列。
